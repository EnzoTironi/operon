# V3-02 - Federated Authority & Multi-Cell Compensation

## Program frame (normative in this document)

Operon is a zero-permanent-UI, agent-agnostic operating kernel. One kernel owns versioned contracts, identity and authority, canonical state, proposals, execution receipts, evidence and the result algebra. CLI, MCP, SDK, generated application surfaces, recipes and enterprise modules are adapters over that kernel and may not reimplement its rules.

Release order is V0 -> V1 -> V2 -> V3. V0 proves external-agent authoring, ingestion, reconciliation and safe action. V1 proves Action Inbox, exact approval, durable execution and honest outcomes. V2 adds post-V0 missions, disposable generated surfaces and the recipes/skills/module ecosystem. V3 adds federation, factory, sovereign operations and formal assurance. A later release cannot be claimed before the preceding gate passes on the same pinned candidate with independent evidence.

Current status is `SPEC_CONSISTENT_NOT_PRODUCT_PASS`: no runtime case has been executed by this dossier.

## Requirements

1. **Selective View Contracts & Uncontracted Link Denial (`S15`, `OPR-FULL-044`)**:
   - Federated view contracts explicitly declare source cell, target cell, allowed schema types, allowed properties per type, allowed link relations, and validity/revocation status.
   - Link traversal or property access outside the negotiated contract is strictly denied with structured `UncontractedLinkTraversalError` (`FULL-ACC-044`).
   - Revoked or expired contracts reject view export and link traversal with `FederationContractRevokedError` or `FederationContractExpiredError`.
2. **Attributed Remote Claims & Uncertainty (`S15`, `OPR-FULL-046`)**:
   - Cross-cell claims remain attributed to the originating cell (`sourceCellId`, `sourceAuthority`, `assertedAt`, `sourceSignature`).
   - Remote claims track explicit uncertainty (`FRESH`, `STALE`, `UNREACHABLE`, `DISPUTED`), and missing attribution is rejected with `FederationAttributionMissingError`.
3. **Multi-Cell Saga Execution & Honest Partial Failure (`S15`, `OPR-FULL-046`)**:
   - Cross-cell operations do NOT promise or invent a global two-phase commit.
   - When a multi-cell saga encounters a remote cell failure, timeout, or partition:
     - The remote failure is recorded with attributed uncertainty (`UNREACHABLE`).
     - Locally committed preceding steps are compensated using registered compensation actions.
     - The saga returns an honest `PARTIALLY_FAILED_COMPENSATED` outcome without pretending a global commit succeeded (`FULL-ACC-046`).
