# V2-05 - Replaceable Model Gateway and 4C Readiness

## Program frame (normative in this document)

Operon is a zero-permanent-UI, agent-agnostic operating kernel. One kernel owns versioned contracts, identity and authority, canonical state, proposals, execution receipts, evidence and the result algebra. CLI, MCP, SDK, generated application surfaces, recipes and enterprise modules are adapters over that kernel and may not reimplement its rules.

Release order is V0 -> V1 -> V2 -> V3. V0 proves external-agent authoring, ingestion, reconciliation and safe action. V1 proves Action Inbox, exact approval, durable execution and honest outcomes. V2 adds post-V0 missions, disposable generated surfaces and the recipes/skills/module ecosystem. V3 adds federation, factory, sovereign operations and formal assurance. A later release cannot be claimed before the preceding gate passes on the same pinned candidate with independent evidence.

Current status is `SPEC_CONSISTENT_NOT_PRODUCT_PASS`: no runtime case has been executed by this dossier.

## Requirements

1. **Replaceable Model Gateway & Production Routing (`OPR-FULL-024`)**:
   - Provider-neutral gateway managing model definitions, versions, token budgets, and routing channels.
   - Versioned Evaluation Suite: Prior to promoting a model to `production` routing, it must execute against a benchmark evaluation suite (action validity, data exposure policy, determinism).
   - If candidate fails evaluation suite: Promotion is blocked with `ModelPromotionDeniedError`; production routing remains pinned to the prior approved model (`FULL-ACC-024`).
2. **Context Fidelity vs. State Correctness (`OPR-FULL-025`)**:
   - A model response citing prompt/context with high linguistic fidelity is strictly checked against 4C-L1 Decision Readiness (correct, complete, current, consistent).
   - If required state evidence is stale or readiness fails, the action is rejected with `ReadinessDeficientError` despite high context fidelity (`FULL-ACC-025`).
3. **Outage Fallback & Token Budgeting**:
   - Outage or changed provider triggers a fallback policy with recorded lifecycle telemetry.
   - Token budget limits per model invocation.

## Executable tests

- `FULL-ACC-024`: Given a new model candidate fails the action suite or data exposure check; when release attempts to promote it **Expected:** production routing is unchanged and promotion is rejected.
- `FULL-ACC-025`: Given a faithful response cites context whose mandatory evidence is stale; when readiness and output quality are checked **Expected:** context fidelity does not authorize action with deficient state.
