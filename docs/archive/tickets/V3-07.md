# V3-07 - Independent Evidence, Dual Ledgers & Adversarial Factory Verification

## Program frame (normative in this document)

Operon is a zero-permanent-UI, agent-agnostic operating kernel. One kernel owns versioned contracts, identity and authority, canonical state, proposals, execution receipts, evidence and the result algebra. CLI, MCP, SDK, generated application surfaces, recipes and enterprise modules are adapters over that kernel and may not reimplement its rules.

Release order is V0 -> V1 -> V2 -> V3. V0 proves external-agent authoring, ingestion, reconciliation and safe action. V1 proves Action Inbox, exact approval, durable execution and honest outcomes. V2 adds post-V0 missions, disposable generated surfaces and the recipes/skills/module ecosystem. V3 adds federation, factory, sovereign operations and formal assurance. A later release cannot be claimed before the preceding gate passes on the same pinned candidate with independent evidence.

Current status is `SPEC_CONSISTENT_NOT_PRODUCT_PASS`: no runtime case has been executed by this dossier.

## Requirements

1. **Task Contract Authorization (`S17`, `OPR-FULL-051`, `FULL-ACC-051`)**:
   - Tasks must declare inputs, scope, dependencies, and required evidence.
   - Protected write operations attempted without an approved task contract are denied with structured `UnapprovedTaskContractError` identifying the missing requirements.
2. **Independent Verifier & Adversarial Scenario Protection (`S17`, `OPR-FULL-052`, `FULL-ACC-052`)**:
   - Implementer cannot approve own outcomes or remove protected tests.
   - If an implementer agent deletes or tampers with protected adversarial scenarios to turn a test suite green, the verifier explicitly rejects the diff with `AdversarialScenarioTamperError` regardless of remaining passing tests.
3. **Contract Compatibility & Version Ownership (`S17`, `OPR-FULL-053`, `FULL-ACC-053`)**:
   - Parallel implementations across modules must strictly honor interface versions and contract ownership.
   - When release integration detects incompatible revisions of the same interface, it fails with `ContractRevisionConflictError` rather than silently adapting.
4. **Controlled Self-Hosting & External Publication Gate (`S17`, `OPR-FULL-054`, `FULL-ACC-054`)**:
   - The platform may build its own packages, but cannot control its own publication authority.
   - Self-modifications to the factory executor require the external gate and prevailing release policy; bypass attempts fail with `ExternalGateRequiredError`.
5. **Dual Ledgers & Adversarial Mutation Defense (`S17`)**:
   - Normative requirements ledger (immutable specification catalogue) is verified against candidate observations ledger.
   - Dropped cases, duplicate cases, zero-assertion passes, forged runners, and checksum mismatches are rejected deterministically with `EvidenceMutationRejectedError`.
