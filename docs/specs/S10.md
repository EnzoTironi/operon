# Self-contained S10

## Program frame (normative in this document)

Operon is a zero-permanent-UI, agent-agnostic operating kernel. One kernel owns versioned contracts, identity and authority, canonical state, proposals, execution receipts, evidence and the result algebra. CLI, MCP, SDK, generated application surfaces, recipes and enterprise modules are adapters over that kernel and may not reimplement its rules.

Release order is V0 -> V1 -> V2 -> V3. V0 proves external-agent authoring, ingestion, reconciliation and safe action. V1 proves Action Inbox, exact approval, durable execution and honest outcomes. V2 adds post-V0 missions, disposable generated surfaces and the recipes/skills/module ecosystem. V3 adds federation, factory, sovereign operations and formal assurance. A later release cannot be claimed before the preceding gate passes on the same pinned candidate with independent evidence.

Current status is `SPEC_CONSISTENT_NOT_PRODUCT_PASS`: no runtime case has been executed by this dossier.

## Three boundaries

A data scenario changes hypothetical state. A definition branch changes candidate schema/code/policy. An execution sandbox limits actual process/file/network/credential/resource access. None automatically provides the others. The current callback runner is not a safe execution boundary for arbitrary generated code.

Support synthetic laboratory, authorized-data scenario and builder workspace as distinct profiles. Broad create/delete/reset rights apply only to authorized hypothetical domain state. Protected identity, real grants, baselines, evaluator code, audit, release keys and budgets are outside those rights. Scenario freedom is not production authority.

## Manifest and storage

ScenarioManifest pins baseline identity and digest, source authorizations, WorldView coordinates, definition/policy/model releases, seed, simulator assumptions, execution profile, permitted processor/broker, limits and retention. Copy-on-write overlays or equivalent isolation keep baseline immutable. Include tenant/ontology/scenario in objects, links, caches, embeddings, streams, jobs and artifacts. Omitted context cannot resolve to main.

Validation baselines are pinned by proposed D12. Rolling exploration may rebase only when visibly configured; each rebase creates a new digest and invalidates dependent review/evidence. Business clocks may simulate past/future dates, while real security time controls grants, expiry and resource limits.

## Containment

Generated code runs in a tested restricted process/container/Wasm profile, never beside production credentials or host control sockets. Egress defaults to deny. An out-of-sandbox broker authorizes model/service destinations and payload classifications. Protect against redirects, alternate address forms, metadata endpoints, shared mounts, background jobs, descendant processes and volume exhaustion. No operational safety claim follows merely from a TypeScript type or Effect Layer.

All scenario outbox, notifications, schedules and receipts use simulated adapters. Production dispatchers reject scenario-issued commands even if routed incorrectly. Cancellation/TTL covers descendants, fibers, queues and late callbacks. Cleanup deletes only owned resources; copied data's confidentiality, retention and purposes survive reset/export/reimport.

## Simulation semantics

Diagnostic mode may explore impossible states or relaxed modeled business rules while preserving containment. Strict mode evaluates the actual candidate production rules. Record unsupported predictions and model applicability. A copied database does not predict physical outcomes. Store actual nondeterministic provider responses for replay; re-invoking a model later is not exact replay.

## Acceptance

Observe egress independently; no emails/payments/webhooks reach live systems. Cross-scenario records/caches are inaccessible. Reset preserves protected evidence. Time travel cannot extend credentials. Budget fan-out and detached workers are bounded. Every UI/CLI/export labels hypothetical status. Test legitimate rapid exploration as well as escape attempts.
