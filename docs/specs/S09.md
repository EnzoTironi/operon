# Self-contained S09

## Program frame (normative in this document)

Operon is a zero-permanent-UI, agent-agnostic operating kernel. One kernel owns versioned contracts, identity and authority, canonical state, proposals, execution receipts, evidence and the result algebra. CLI, MCP, SDK, generated application surfaces, recipes and enterprise modules are adapters over that kernel and may not reimplement its rules.

Release order is V0 -> V1 -> V2 -> V3. V0 proves external-agent authoring, ingestion, reconciliation and safe action. V1 proves Action Inbox, exact approval, durable execution and honest outcomes. V2 adds post-V0 missions, disposable generated surfaces and the recipes/skills/module ecosystem. V3 adds federation, factory, sovereign operations and formal assurance. A later release cannot be claimed before the preceding gate passes on the same pinned candidate with independent evidence.

Current status is `SPEC_CONSISTENT_NOT_PRODUCT_PASS`: no runtime case has been executed by this dossier.

## Normative specification


**Status:** proposed executable contract; source decisions remain OPEN until explicitly approved.

## Role
Implement the other agent's sentinel proposal as an independent semantic reviewer, not an authorization oracle. It reviews an authenticated immutable bundle containing task/grant/policy, WorldView, actual prepared effects, recipients, evidence and relevant mission history. A statement that another model approved is not a valid SentinelReview.

## Review contract
A review records bundle digest, reviewer identity, model/provider/config/prompt releases, scope, evidence references, structured findings, limitations, recommended controls, expiration and result class. Validate references against the permitted bundle; nonexistent evidence or malformed output cannot count as favorable review. Review caches bind all material dependencies and permission scope.

The proposer cannot edit reviewer instructions, shared memory, protected examples or evaluation labels. A different model alone does not establish statistical independence. The reviewer receives read-only tools and an independently governed role. Copied malicious instructions remain untrusted source content. A review recommendation cannot mint an IntentGrant, bypass a deterministic denial, impersonate an approver or execute the proposed business effect.

## Required and advisory coverage
Coverage is a policy decision preserved as D11. For mandatory review: unavailable, stale, malformed or incomplete results hold the operation or use an explicitly authorized fallback. For certified synthetic exploration: advisory review may be unavailable while the experiment continues visibly UNREVIEWED. Neither state authorizes promotion. High-severity uncertainty cannot be collapsed into a numeric confidence threshold.

Sequence review includes previous attempts, cumulative reservations and suspicious action splitting. Limit resubmissions and reviewer shopping. An appeal preserves prior findings. A narrowly authorized pause request goes through the control service; resumption and broader stop authority remain separate. Post-action monitoring cannot retroactively prevent an already completed effect.

## Real evaluation
Develop a held-out labelled corpus of benign and adversarial tasks, with separate versions for training/development and release evaluation. Use actual selected models; deterministic doubles test plumbing only. Measure missed hazards, false holds, task success, latency, review burden, data exposure and cost. Report sample sizes, uncertainty and failure correlation by risk class. Thresholds are approved in D14 before evaluation, not fitted afterward to force a pass.

## Acceptance
Injection in retrieved evidence, fabricated favorable findings, stale bundles, confidential reviewer-only facts, repeated appeal, budget splitting, model outage, invalid references, disagreement and legitimate rare actions. At least one positive mission finishes with no unnecessary escalation. Review artifacts must distinguish semantic evaluation from formal proof.
